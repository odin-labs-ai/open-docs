# Odin Labs — public teaching principles

The academy's examples reflect four general engineering principles:

- Consume shared core capabilities rather than duplicating platform logic.
- Check authorization for the specific tenant and operation before accessing data.
- Verify the actual artifact before reporting success.
- Repair failures with a forward correction and verify it.

This public learning summary is maintained in [Odin Open Docs](https://github.com/odin-labs-ai/open-docs). Learn more about [Odin Labs](https://www.odin-labs.ai).
