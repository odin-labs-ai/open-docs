# Odin branding

`public/odin-logo.svg` uses the logo path and viewBox served in the header of
https://www.odin-labs.ai, retrieved on 2026-09-07. The website's CSS gradient
variables were resolved to their served values: neon lime `#39ff14` and neon cyan
`#00ffff`, so the original mark works as a standalone SVG. The shape is unchanged.

Odin's name and logo identify the publisher. They remain Odin brand assets;
permission to reuse the code does not grant trademark rights or imply endorsement.
